# SocioLine Codex Instructions

This repository holds the approved SocioLine metaverse development brief.

Before implementing or modifying the website:
1. Read `docs/socioline-reference/CODEX_MASTER_PROMPT.md`.
2. Read `docs/socioline-reference/SocioLine_3D_City_Masterplan_v2.md`.
3. Follow `docs/socioline-reference/METAVERSE_ACCEPTANCE_CHECKLIST.md`.
4. Use the logo, zoning map, and organizational blueprint as references, not as proof of a live product.

Keep the experience a **playable immersive 3D city** with original life-simulation/anime-inspired avatars and connected districts. Never substitute a static hero or cards for gameplay.
Keep public pages accessible via independently crawlable server-rendered HTML, without WebGL or avatar login.
Implement an actually playable vertical slice first; run checks; report PASS/PARTIAL/BLOCKED accurately.
Do not publish or deploy without authorization. Avoid fabricated community results, news, participant identities, or testimonials.
