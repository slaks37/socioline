# SOCIOLINE METAVERSE CITY — Acceptance Checklist V2

This checklist is an implementation test plan, not proof that features already exist.

## M1: playable, polished vertical slice
- [ ] Public SSR SocioLine homepage and direct HTML routes work without JavaScript/WebGL.
- [ ] Enter World portal loads game with optional/skippable intro and visible progress.
- [ ] Male/female visual presets; optional 360-degree preview and cosmetic customization.
- [ ] Stylized human avatar with believable idle/walk/run animations (explicitly label any temporary models).
- [ ] Third-person camera, movement, collision/gravity and return/reset location.
- [ ] Elevated arrival reveal → Central Plaza in the same 3D environment.
- [ ] At least two connected blocks; varied roads, sidewalks, props, lighting and skyline.
- [ ] Ambient motion (non-player NPC pedestrians or other honest local ambience).
- [ ] One enterable building with a real 3D interior and a content interaction.
- [ ] At least two interactable landmarks; accessibile HTML panel with real canonical URL.
- [ ] Closing information returns to previous avatar/world location.
- [ ] Accessible standard website mode, controls help, settings, WebGL-failure fallback.
- [ ] Representative screenshot or walkthrough recorded and honestly evaluated.

## M2: connected city and metaverse feel
- [ ] THE WORD West, THE WORLD Center, THE WORK East — physically connected city.
- [ ] Each district has recognizable landmarks, streets and environment identity.
- [ ] Walkable route between districts without forced teleportation.
- [ ] Working minimap, fast travel, district indicators and mobile controls.
- [ ] Billboard editorial system matches server-visible HTML source of truth.
- [ ] Deep link from content page to 3D landmark and vice versa.
- [ ] Reasonable FPS observed and reported on desktop/mobile target devices.
- [ ] Game HUD isn't replaced by giant permanent HTML content panels.

## SEO and accessibility gate
- [ ] Meaningful direct GET HTML (title, H1, body copy, anchors) for home, Word, World, Work.
- [ ] Blog and genuine news items have published HTML routes, correct structured metadata.
- [ ] Sitemap/robots/canonicals/RSS ready, excluding drafts and non-public pages.
- [ ] Search visitors can read without avatar/login/WebGL.
- [ ] Keyboard accessible overlays, readable focus states, reduced motion, mute, low graphics/2D fallback.
- [ ] No fake multiplayer users, events, impact claims, or production news.

## Correct status reporting
Mark each group PASS, PARTIAL or BLOCKED with evidence. A screenshot alone does not prove playability or SEO.
