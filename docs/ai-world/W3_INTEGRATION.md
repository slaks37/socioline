# Dari distrik ke dokumen kerja

| Distrik | Interaksi | Dokumen di laboratorium |
|---|---|---|
| The Word | Masuk Grand Library, buka Encounter, lanjutkan ke Understand, Discern dan Commit. | Calling Map dan Mission Charter. |
| The World | Buka kios materi, dengarkan komunitas, pelajari konteks, aset dan peluang. | Cultural Map, Community Profile, Stakeholder Map dan Opportunity Brief. |
| The Work | Tinjau peran, desain bersama, model, eksperimen, pelayanan dan evaluasi. | Value Proposition Canvas, Mission Model Canvas, Experiment Evidence, Delivery Log, Follow-up Plan, Business Model, Project Proposal dan Impact Report. |

Panel Dokumen kerja W3 menyediakan kolom sesuai jenis dokumen. Pemain menyimpan data dalam ruang privat dan dapat mengunduh Markdown untuk dibahas dengan mentor atau komunitas. Dokumen menyimpan versi sehingga suntingan dari tab lama dapat ditolak. Pencatatan sumber, izin komunitas, dan keterbatasan bukti merupakan bagian dari tugas pembelajaran.

URL utama ialah /the-word, /the-world dan /the-work. Tiap tahap memiliki halaman HTML sendiri serta navigasi tanpa WebGL. Portal laboratorium menghubungkan direktori kota ke /worlds. Asisten di ruang privat mengenali perintah terbatas untuk navigasi, dokumen, pohon atau bangku. Perubahan objek melewati konfirmasi dan otorisasi server.
